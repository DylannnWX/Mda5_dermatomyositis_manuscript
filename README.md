# MDA5 Dermatomyositis Manuscript

Welcome to our GitHub repository! This repository contains the custom scripts, analysis pipelines, and associated software requirements used for our **MDA5 dermatomyositis manuscript**.

The repository includes code for the following analyses:

## 1. A-to-I (A-to-G) RNA Editing Analysis

Detection and quantification of **A-to-I RNA editing**, represented as A-to-G mismatches, using strand-specific SMARTer RNA-seq data.

**Environment:**

* Python 3

**Required software/packages:**

* argparse (v1.1)
* pandas (v2.3.3)
* numpy (v2.4.2)

## 3. Transposable Element Counting by Class

This analysis uses mapped BAM files to quantify differentially expressed transposable elements (TEs) and summarize them by TE class.

The pipeline:

* Filters BAM files to retain primary alignments.
* Identifies TEs differentially expressed between patients and healthy controls (HCs), using a threshold of `|log2FC| > 1`.
* Groups the differentially expressed TEs by TE class.
* Calculates the total signal associated with each TE class.

**Environment:**

* HMS O2 computing cluster

**Required software:**

* gcc (v14.2.0)
* samtools (v1.21)
* bedtools (v2.31.0)
* Python (v3.13.1)

**Reference annotation:**

* Repbase TE annotation, downloaded directly in BED format

## 5. TEtranscripts Log2 Fold-Change Shrinkage

This analysis takes the differential-expression results generated by **TEtranscripts/TEcount** and applies log2 fold-change (LFC) shrinkage to reduce unstable or disproportionately large LFC estimates associated with low-abundance transposable elements.

The shrinkage analysis uses the `baseMean` and LFC values from the TEtranscripts differential-expression output to generate more stable effect-size estimates for downstream visualization and interpretation.

Similar LFC-shrinkage approaches have been used in published TE-expression studies using **TEtranscripts/TEcount followed by DESeq2-based shrinkage**, including analyses applying the `apeglm` shrinkage estimator. Additional methodological details and literature references are provided in the README within the corresponding analysis directory.

**Input:**

* Raw TEtranscripts differential-expression results

**Output:**

* LFC-shrunk TEtranscripts results for downstream analysis and visualization

**Environment:**

* Jupyter Notebook
* Python 3

## 6. L1 Transcriptional Direction and Gene Relationship Analysis

The `GENE_L1_relationship_MAPQ10` analysis examines the genomic context and transcriptional direction of expressed **LINE-1 (L1)** loci.

The pipeline:

* Intersects RepeatMasker L1 regions with human gene annotations.
* Separates L1 loci by genomic plus and minus strand.
* Filters strand-specific RNA-seq alignments using `MAPQ >= 10`.
* Quantifies reads corresponding to **L1-sense** and **L1-antisense** transcription.
* Retains L1 loci supported by at least 10 reads.
* Annotates expressed L1 loci relative to genes using **ChIPseeker** and the hg38 KnownGene annotation.
* Compares L1 genomic orientation with gene orientation within intronic, exonic, promoter, downstream, and UTR regions.
* Generates read-weighted genomic composition plots in Jupyter Notebook.

**Input annotations:**

* `Repeatmasker_IGV_magic_L1.bed`
* `Human_genes.bed`

**Environment:**

* HMS O2 computing cluster
* R
* Jupyter Notebook / Python 3

**Required software/packages:**

* gcc (v14.2.0)
* samtools (v1.21)
* bedtools (v2.31.0)
* ChIPseeker
* org.Hs.eg.db
* TxDb.Hsapiens.UCSC.hg38.knownGene
* openxlsx
* pandas
* numpy
* matplotlib

Additional methodological details and scripts are provided in the README within the `GENE_L1_relationship_MAPQ10` directory.
